  SpotBugs).
- The project targets **Java 25**, so the prompt-engineering constraint example uses Java 25, not 21.
- The MCP connector defines exactly 10 tools in `McpTools.java`: `get_my_team`,
  `list_expense_categories`, `list_my_claims`, `get_claim`, `check_claim`, `create_draft_claim`,
